# Dova Locks

Your base. Your PIN. Your questionable choice of roommates.

**Version 1.16** adds door sharing, an admin Ward limit, and a green Ward device icon. Updated for ICARUS Week 258.

[Download](https://github.com/VariantCreator/Dova-Locks/releases/latest) | [Nexus](https://www.nexusmods.com/icarus/mods/325)

## Install

Close ICARUS and stop the server. Extract the ZIP and replace `Dova-Locks_P.pak` in `Icarus/Content/Paks/mods`.

Use **1.16 on the server and every player**. Back up your prospect and A/B lock saves, keep one active Dova copy, and rebuild any merge containing it. For Jimk72's IMM, replace the old imported Dova entry, extract the new PAK as a mod, and rebuild your list.

## Use it

Hold **Shift + Interact** on a supported object for lock controls. Learn **Dova's Ward** beside Flow Meter in Tier 4. Craft it at a Fabricator or Manufacturer, then tap **Interact** on the placed Ward.

Choose a known player or enter their Steam ID without sharing the PIN. Share a single door, chest, or bench through the **Object** tab. A shared door grants open and close access. Shared chests and benches also allow taking items. Pickup and lock controls still need permission.

Link your base, choose your boundary color, and join up to three Wards. Server admins can set the connected Ward limit from one to three. Anyone can repair. Renovations need permission.
