## Install

Close ICARUS and stop the server. Extract the ZIP and put `Dova-Locks_P.pak` in `Icarus/Content/Paks/mods`. Create `mods` if needed, replace the old PAK, and keep one copy.

**The server and every player need the same PAK.** Back up your prospect and both A/B lock saves before updating. Keep those saves.

## Use it

- **Regular locks:** Look at a supported door, window, container or bench. Hold **Shift**, then hold your **Interact key**. Set a four-digit PIN; use **Link connected base** for the connected structure.
- **Dova's Ward:** Craft it where you craft the Flow Meter, then place it and **tap Interact**. Set a PIN and choose a **1–60 m** radius.
- **Joined Wards:** Up to three touching Wards with the same owner share access and a name. Each keeps its own PIN. Removing one lock leaves the others alone.
- **Your display:** Pick your Ward color, opacity and brightness. Your screen, your eyeballs.

Anyone can repair. Upgrades, pickup and crop removal need permission. Members can private-lock chests they placed. Server admins get a separate panel after `/AdminLogin`.
